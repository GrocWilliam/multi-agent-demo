# Notes demo

API Express + TypeScript minimale (notes en mémoire, sans authentification).

```
npm install
npm run dev
```

Frontend (React + Vite, dossier `frontend/`), dans un second terminal :

```
cd frontend
npm install
npm run dev     # http://localhost:5173 (proxy /api -> localhost:3000)
```

La documentation de suivi est dans `docs/` (voir `docs/README.md`).
